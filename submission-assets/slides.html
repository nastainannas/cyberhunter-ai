CYBERHUNTER AI

Masalah

  • Scanner keamanan umumnya mahal, rumit, atau hanya mendeteksi pasif (headers, banner)
  • Bug bounty butuh active probing: SQLi, XSS, command injection — yang sulit dilakukan manual pada website besar
  • Crawler konvensional melewatkan parameter tersembunyi: POST body, JSON API, field hidden, endpoint yang tidak ter-link
  • Situs modern memakai anti-bot JS challenge (WAF splash) yang membuat scanner biasa buta total
  • Hasil scan mentah sulit dibaca — butuh evidence, payload persis, dan laporan siap-kirim
2
CYBERHUNTER AI

Solusi

Satu platform web untuk security testing terotorisasi:

Crawler Cerdas

Crawl multi-halaman, subdomain, form, JS bundle — plus parameter mining (±75 nama param umum) dan filename mutation untuk endpoint tersembunyi.

Active + Passive OWASP Top 10

SQLi (error/blind/UNION extraction), XSS (reflected/stored/DOM via headless browser), command injection, LFI, SSRF, XXE, open redirect, CORS, security headers, exposed secrets.

Anti-Bot Solver

Challenge JavaScript (WAF splash) diselesaikan otomatis via headless Chromium — clearance cookie dibawa ke request berikutnya.

Report & Evidence

Setiap temuan menyimpan payload pemicu, parameter, endpoint, request/response mentah, severity, confidence — diekspor sebagai laporan HTML bilingual (EN/ID) format XRay.

CYBERHUNTER AI

Deteksi Vulnerability

SQL Injection

Error-based (multi-DBMS pattern), time-based blind dengan konfirmasi ganda anti-false-positive, dan UNION extraction hingga 15 kolom dengan marker database.

XSS

Reflected, stored, dan DOM XSS diverifikasi via browser headless — payload harus benar-benar mengeksekusi, bukan sekadar ter-reflect.

Command Injection

Marker aritmatika CYBERHUNTER_$((7*7)) → output CYBERHUNTER_49 — mustahil muncul dari refleksi biasa.

CVE Surface

Fingerprint versi PHP/CMS → ruleset CVE (php2shell CVE-2026-109618/619, Drupalgeddon2, Joomla, Laravel, WordPress, phpMyAdmin, ThinkPHP…) + verifikasi aktif read-only.

CYBERHUNTER AI

Etika & Keamanan

  • Active probing hanya untuk sistem milik sendiri atau dengan otorisasi tertulis — gating eksplisit di UI
  • Cookie session di-scope per-origin — tidak pernah bocor ke domain lain
  • Nilai cookie disensor di log, database, dan laporan export
  • Payload non-destruktif: marker aritmatika, canary string, error-based — tanpa exploit berbahaya
  • robots.txt disrespect — deteksi "Disallow: /" menghasilkan peringatan scope
  • Rate limiting via request delay yang dapat diatur (0–500ms+)
